Requisitos Técnicos Hospedagem do Projecto TSHOOT

Bom dia,

Gostaria de apresentar os requisitos técnicos do projecto TSHOOT Troubleshoot Soluções Tecnológicas e solicitar recomendação de plano de hospedagem compatível com as tecnologias utilizadas.

Tecnologias Utilizadas no Projecto

Frontend Site Institucional

HTML5 CSS3 JavaScript ES6+ Vue.js 3 Chart.js Font Awesome

Site estático com framework Vue.js via CDN. Animações CSS, carrossel de imagens, formulário de contacto, tracking de visitantes via API.

Backend CRM Administrativo

PHP 8.2 Laravel 12 SQLite / MySQL Composer

Sistema CRM completo com dashboard, gestão de contactos, tracking de visitantes, CMS para conteúdo do site, upload de imagens.

Base de Dados

SQLite MariaDB 11.4

SQLite para desenvolvimento local. MySQL/MariaDB para produção. Múltiplas tabelas: users, contacts, visitors, banners, site_contents, site_settings.

Funcionalidades

CMS Admin API REST Tracking Charts Upload

Banners CRUD, editor de conteúdo, configurações do site, dashboard com 6 gráficos, formulário de contacto, geolocalização IP.

Requisitos Mínimos do Servidor

  • PHP 8.1 ou superior (projecto usa PHP 8.2)
  • MySQL ou MariaDB (base de dados relacional)
  • Extensões PHP: openssl, pdo, pdo_mysql, mbstring, tokenizer, xml, ctype, json, bcmath, fileinfo, gd
  • Composer (gestor de dependências PHP)
  • Mod_rewrite activo no Apache
  • Permissões de escrita na pasta storage/
  • Certificado SSL/HTTPS
  • Acesso SSH para comandos de instalação
  • Suporte a ficheiros .htaccess (Apache)

Porquê o Plano Essencial (Kz 3,150/mês)?

  • 2 GB de RAM mínimo recomendado para Laravel 12 em produção
  • 50 GB de armazenamento SSD suficiente para site + CRM + imagens
  • Terminal SSH necessário para Composer e comandos artisan
  • cPanel com Imunify360 gestão fácil + protecção de segurança
  • 500 mil ficheiros Laravel gera muitos ficheiros, 300K é seguro
  • Até 5 sites permite hospedar o site público e o admin CRM separadamente
  • Certificado SSL gratuito HTTPS obrigatório para formulários
  • Teste grátis 7 dias sem compromisso para validar antes de contratar

Observações Importantes

  • O plano Pessoal (1 GB RAM) pode ser insuficiente para Laravel risco de timeout em operações pesadas
  • Todos os planos incluem cPanel com instalador de aplicações (Softaculous)
  • Compatível com PHP, Python, NodeJS suporta todo o stack do projecto
  • Backup automático incluído em todos os planos
  • Suporte técnico local em Luanda
  • Activación imediata após confirmação do pagamento

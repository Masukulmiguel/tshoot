01 Visão Geral do Projeto

O TSHOOT Admin é um sistema de administração completo para gestão de conteúdo, contactos, visitantes e configurações do site tshoot-angola.com. O sistema foi desenvolvido pela CodingLife Dev utilizando tecnologias modernas e seguras, seguindo as melhores práticas de desenvolvimento web.

Arquitectura Geral

O sistema segue o padrão MVC (Model-View-Controller) com uma API pública para o site frontal e um painel administrativo protegido por autenticação. A infraestrutura utiliza cloud hosting com base de dados PostgreSQL gerida.

03 Arquitectura do Sistema

  1. 1
    Frontend Público (site.html) — Página estática HTML/CSS/JS com Vue.js que consome a API pública de conteúdo. Apresenta serviços, equipa, blog, galeria e formulário de contacto.
  2. 2
    API Pública (/api/content) — Endpoint JSON que retorna todo o conteúdo do site (banners, serviços, posts, equipa, configurações). Throttled para abuso.
  3. 3
    Painel Administrativo (/admin) — Interface protegida por autenticação com dashboard, gestão de contactos, visitantes, serviços, posts, banners, equipa, galeria, parceiros e configurações.
  4. 4
    API de Tracking (/api/track) — Endpoint para registo de visitantes com geolocalização, dispositivo e páginas visitadas.
  5. 5
    API de Contactos (/api/contact) — Formulário público para submissão de contactos com throttle de abuso.

05 Medidas de Segurança

O sistema implementa múltiplas camadas de segurança:

Autenticação Rate Limiting CSRF Protection XSS Prevention HSTS Session Security Password Hashing (Bcrypt) Input Validation SQL Injection Prevention (Eloquent) Security Headers Brute Force Protection HTTPS Enforcement
Medida Implementação
Autenticação Login com email/senha, sessão regenerada após login, logout seguro
Rate Limiting 5 tentativas = 10 min bloqueio no login; throttle em APIs públicas
Senhas Bcrypt hashing, mínimo 8 caracteres, confirmação obrigatória
Headers HSTS, X-Frame-Options DENY, X-Content-Type-Options, Referrer-Policy
CSRF Token em todos os formulários, excepção apenas em APIs públicas
SQL Injection Eloquent ORM com binding paramétrico em todas as queries
XSS Blade auto-escaping `{{ }}`, sanitização de input em JavaScript
Ficheiros Validação MIME, max 5MB, apenas imagens (jpg, png, webp)
